# 🧙‍♀️ 마음의 약국

**마음이 지친 손님들에게 꼭 필요한 감정을 처방하는 픽셀 RPG 게임**

어느 작은 마을에 특별한 약국이 있습니다.

이곳에서는 감기에 걸렸을 때 먹는 약도, 상처에 바르는 연고도 팔지 않습니다. 대신 용기, 위로, 희망, 평온처럼 눈에 보이지 않는 감정을 물약으로 만들어 판매합니다.

당신은 이 약국을 운영하는 초보 마녀입니다.

약국을 찾아오는 손님들의 이야기를 듣고, 감정을 연구하고, 가장 필요한 물약을 처방해 주세요.

과연 당신은 모든 손님의 마음을 이해하는 최고의 마녀가 될 수 있을까요?

---

## 🎮 게임 소개

**마음의 약국**은 손님과의 대화, 감정 연구, 물약 제조, 약국 운영을 결합한 2D 탑뷰 픽셀 게임입니다.

단순히 정답을 고르는 것이 아니라, 손님의 고민을 듣고 어떤 감정이 필요한지 직접 판단해야 합니다.

### 주요 기능

**💬 손님 상담**
- 약국을 찾아오는 다양한 손님과 대화
- 질문을 통해 손님의 고민과 감정 파악
- 상담 결과에 따라 달라지는 반응과 보상
- 특별한 사연을 가진 손님 등장

**🧪 감정 연구와 물약 제조**
- 여러 감정을 조합해 새로운 물약 연구
- 연구한 물약을 처방에 활용
- 물약 종류를 늘려 나가는 수집 요소

**🏡 나만의 약국 운영**
- 손님 상담과 처방으로 코인 획득
- 상점에서 재료와 아이템 구매
- 약국 내부 꾸미기 및 물약 전시

**🌳 마을 탐험**
- 약국 밖으로 이동해 마을 탐험
- 주변 오브젝트와 상호작용
- 숨겨진 발견 요소와 보상

**⭐ 성장과 미션**
- 정확한 처방 횟수에 따른 마녀 등급 성장
- 일일 미션 달성 보상
- 특별 손님과 다양한 감정 반응

## 🕹️ 조작 방법

| 동작 | PC | 모바일 |
|---|---|---|
| 캐릭터 이동 | WASD / 방향키 | 화면 방향키 |
| 상호작용 | E | 상호작용 버튼 |
| 상담 및 선택 | 마우스 클릭 | 화면 터치 |
| 메뉴 이용 | 마우스 클릭 | 화면 터치 |

PC와 모바일 브라우저에서 플레이할 수 있도록 제작하고 있습니다.

---

## 🧙 게임 진행 방법

1. 약국을 찾아온 손님에게 다가가 대화를 시작합니다.
2. 손님의 고민을 듣고 질문하며 필요한 감정을 파악합니다.
3. 감정을 연구하고 적절한 물약을 준비합니다.
4. 손님에게 물약을 처방하고 결과를 확인합니다.
5. 획득한 코인으로 약국을 발전시키고 새로운 손님을 맞이합니다.

## 🚀 로컬 실행

1. 저장소를 클론합니다.

```bash
git clone https://github.com/ge323/emotion-apothecary.git
```

2. 프로젝트 폴더로 이동합니다.

```bash
cd emotion-apothecary
```

3. JavaScript 파일을 수정한 경우 빌드를 실행합니다.

```bash
node build.js
```

4. 로컬 웹 서버를 실행하여 `index.html`에 접속합니다.
